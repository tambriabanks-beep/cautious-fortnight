# TAMB Consulting Website

Plain HTML, CSS, and JavaScript site designed for GitHub Pages.

## Structure
- `index.html` Home
- `services.html` Services
- `about.html` About
- `privacy.html` Privacy Policy
- `accessibility.html` Accessibility
- `terms.html` Terms & Conditions
- `css/styles.css` Global styles
- `js/main.js` Mobile navigation
- `images/` Add founder photos here

## Adding photos
Replace the photo placeholder blocks with image elements or update the HTML to point to your files. Recommended filenames are shown inside the placeholders.

## GitHub Pages
Upload the contents of this folder to the root of your GitHub repository. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose the main branch and `/ (root)`, then save.

## Notes
The legal pages are a starting website draft, not legal advice. Review them for your business, jurisdiction, privacy practices, and any third-party tools used by the live site before publishing.
